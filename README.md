# Breast Cancer Diagnosis Analysis

## Overview

This project analyzes breast cancer diagnosis data using statistical and machine learning techniques.

## Methods

- Principal Component Analysis (PCA)

- Clustering Analysis

- Correlation Analysis

- Data Visualization

## Repository Contents

- Dataset (data.csv)

- R Source Code

- Analysis Report

- Visualizations

- Results Table

## Key Findings

The project demonstrates how PCA can reduce dimensionality while preserving meaningful information and how clustering techniques can reveal hidden patterns within the dataset.
